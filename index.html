Privacy Policy

Last updated: August 9, 2026

This privacy policy describes how this application ("the App"), a self-hosted instance of Postiz, handles information when connecting to Facebook and Instagram on behalf of its owner/operator.

Who operates this App

This App is operated by a single individual for personal use, to schedule and publish posts to their own Facebook Pages and connected Instagram account. It is not offered as a public service to other users.

What information is accessed

The App connects to the Facebook Graph API using OAuth to access only the information necessary to schedule and publish content, including:

  • Basic profile information needed to authenticate the connection
  • A list of Facebook Pages the operator manages
  • Permission to publish posts, images, and engagement content to those Pages
  • Basic Page insights, where applicable

How information is used

Information retrieved via the Facebook API is used solely to display connected Pages within the App and to publish content that the operator has explicitly composed and scheduled. No information is sold, shared with third parties, or used for advertising purposes.

Data storage

Access tokens and any content queued for publishing are stored on infrastructure controlled directly by the operator and are not transmitted to any third party beyond what is required to communicate with the Facebook API itself.

Data retention and deletion

Data is retained only as long as needed to operate the App. The operator may delete stored tokens and associated data at any time by disconnecting the integration or removing the App's access via Facebook's Business Integrations settings at facebook.com/settings?tab=business_tools.

Third parties

This App does not share data collected via the Facebook API with any third party. It communicates only with Facebook's own API endpoints to publish content.

This policy applies to the use of the Facebook Graph API by this self-hosted Postiz instance, in accordance with Meta Platform Terms.
